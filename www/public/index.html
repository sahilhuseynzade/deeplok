Features

Everything Freedom does, living in your bar

One click on the shield: start a block, build lists, set the week's rhythm.

Blocklists

Named groups of websites and apps — youtube.com, steam, discord. Mix and match per session.

Instant sessions

Pick lists, pick 15 minutes or 12 hours, block now. The bar counts down with you.

Scheduled starts

Choose a date and time; the block arms itself. Tomorrow-you doesn't get a vote.

Recurring schedules

Mon–Fri 09:00–12:00, weekend evenings, overnight ranges — the week runs on rails.

App blocking

Windows of blocked apps close the moment they appear, with a polite notification.

A better wall

Blocked visits land on a calm page with a countdown and a reminder of what the hour is worth — not a browser error.

Locked mode

A locked session cannot be ended, weakened, or uninstalled before it's done. It's enforced by a root-owned helper with its own lock ledger — killing the shell, editing state files, or rage-quitting the panel changes nothing. Future-you will be annoyed. Present-you is counting on it.

Install

Three steps, then it runs itself

Open source, auditable, and honest about its limits.

1

Install the plugin

One command adds the shield to your bar.

omarchy plugin add \
  https://github.com/sahilhuseynzade/deeplok.git \
  --enable
2

One-time system setup

Click Install system helper in the panel and authenticate once. Website blocks then apply unattended — even at 2 AM, with nobody around to click a dialog.

3

Set the rhythm

Build blocklists, start a session, or schedule the week. The bar shows the countdown; the panel holds the controls.

Fine print

Honest limitations

  • You have root on your own machine — Deeplok raises the friction, it doesn't make bypass impossible. (Neither does anything else.)
  • Sites that hard-force HTTPS (YouTube, Instagram…) show the browser's own error instead of the block page. They're still blocked.
  • Browsers with DNS-over-HTTPS enabled can bypass hosts-based blocking — turn DoH off for best results.
